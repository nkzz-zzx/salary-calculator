## 更新与部署

站点使用纯静态 HTML。根目录保留页面源文件，`dist/` 为 EdgeOne 的发布目录。
修改页面时，同步更新根目录及 `dist/` 中的对应文件，再提交到 `main` 分支。
EdgeOne 已关联本仓库，`main` 推送会自动部署到 `zzxai.cn`；无需安装依赖或编译命令。

本地预览：运行 `python3 -m http.server 8000 --directory dist`，打开 `http://localhost:8000`。

## 工资与个税计算器

#### 介绍
工资与个税计算器是一款基于 Web 的综合薪资计算工具，帮助用户快速准确地计算税后工资、五险一金、奖金个税等。该工具支持多种计税模式，并提供直观的可视化图表和月度明细表，方便用户了解薪资构成和税务情况。

#### 主要功能
- **薪资构成计算**：支持输入基本工资、绩效工资、岗位津贴等多个薪资项目
- **五险一金计算**：自动计算养老保险、医疗保险、失业保险、工伤保险、生育保险及住房公积金
- **专项附加扣除**：支持子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人等专项附加扣除
- **奖金个税计算**：支持单独计税和并入工资两种奖金计税方式
- **多种计税模式**：提供分项计算、合并计算、混合计算三种计税方式对比
- **可视化图表**：通过柱状图直观展示税前工资、税后收入、各项扣除及税额构成
- **月度明细表**：自动生成全年12个月的税后工资明细表
- **KPI指标展示**：快速查看全年收入、纳税总额、平均月薪等关键指标

#### 软件架构
本项目采用纯前端技术栈实现，是一个单页面应用（SPA），无需后端服务器支持。主要技术特点：

- **HTML5**：构建页面结构
- **CSS3**：采用 Grid 和 Flexbox 布局，实现响应式设计
- **JavaScript**：处理薪资计算逻辑、图表渲染和数据交互
- **模块化设计**：计算逻辑与界面分离，便于维护和扩展

#### 安装教程
1. 确保已安装现代浏览器（Chrome、Firefox、Edge、Safari 等）
2. 克隆或下载本仓库代码到本地
3. 直接在浏览器中打开 `index.html` 文件即可使用

#### 使用说明
1. **输入薪资信息**：在左侧输入区填写税前工资、各项补贴、奖金等信息
2. **设置扣除项目**：根据实际情况填写五险一金缴纳金额和专项附加扣除
3. **选择计税方式**：根据个人收入情况选择合适的计税模式（分项/合并/混合）
4. **查看计算结果**：中间区域会实时显示计算结果和对比数据
5. **分析图表数据**：通过柱状图直观了解各项收入和支出构成
6. **查看月度明细**：底部表格展示全年各月的税后工资明细
